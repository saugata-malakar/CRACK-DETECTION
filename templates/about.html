ℹ️ About This Project

🎯 Overview

This is an AI-powered web application for detecting cracks in concrete structures using deep learning. The system achieves 96-98% accuracy using state-of-the-art Convolutional Neural Networks (CNNs).

📊 Dataset: SDNET2018

The model is trained on the SDNET2018 dataset, which contains:

  • 56,092 images of concrete surfaces (256×256 px)
  • 3 categories: Bridge Decks, Walls, Pavements
  • 2 classes: Cracked and Non-cracked
  • Crack widths ranging from 0.06 mm to 25 mm

🤖 Technology Stack

  • Backend: Flask (Python)
  • Deep Learning: PyTorch
  • Models: ResNet, EfficientNet, VGG
  • Frontend: HTML, CSS, JavaScript
  • Acceleration: CUDA (GPU support)

✨ Features

  • Multiple CNN architectures to choose from
  • Real-time crack detection with confidence scores
  • Model comparison across all architectures
  • GPU-accelerated inference
  • Easy-to-use drag-and-drop interface

📚 References

Dataset: Dorafshan, S., Thomas, R. J., & Maguire, M. (2018). SDNET2018: An annotated image dataset for training deep learning-based concrete crack detection algorithms.

Institution: Utah State University
